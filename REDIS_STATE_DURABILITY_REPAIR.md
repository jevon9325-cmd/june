The SQLite store holds one current full image and small immutable date-baseline records; it does not redesign trading or settlement authority.

Baseline persistence commits before the cache write; cache OOM is logged and does not destroy durable truth.

Missing live Redis state still requires recovery even if a checkpoint exists. No stale full image is automatically replayed. If checkpoint and Redis diverge after OOM, startup blocks rather than choosing the older object. This deliberately leaves broker/durable-evidence recovery as an explicit incident: a checkpoint is recoverable evidence, not proof that no later broker action occurred.
